# 全文語意核對紀錄（2026-09-06）

本輪已完成文字層面的全文核對與校訂。審查完成後，已依使用者要求同步電腦與掌機的裝置測試版，並在使用者回報未見問題後整理為 tw-v1.0.10 發布內容，詳見文末。這不是「所有遊戲情境皆已實測」或「翻譯完全無誤」的保證。

## 範圍與結果

- 以美版英文模式的原版文字為依據，逐項對照 68 份 MSBT、5,040 個文字項目，包括介面、教學、對話、圖鑑、空項目與原有注音資源。
- 語意修正清單共 891 筆精確替換，影響 697 個項目。另保留 4,342 個項目，1 個項目待確認。
- 697 個修改項目均已回讀英文與修改後譯文；回讀期間修正了新譯的句子銜接、操作限定與慣用語解讀。
- 加上本輪基準已包含的 3 則劍術老師修正，實際文字相較 tw-v1.0.9 共變更 700 個項目。
- 修正記錄與逐條理由見 [../text/semantic_pass.json](../text/semantic_pass.json)；套用順序為既有三層校訂之後，再套用本輪清單。

沿用已確認的官方繁體譯名及既有民間慣用名，不以英文直譯全面更名。海盜口令、刻意口音、誤聽笑話、製作人員名單、古語與原版占位內容均保留。
