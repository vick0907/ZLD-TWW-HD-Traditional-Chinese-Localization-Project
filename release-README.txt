薩爾達傳說 風之律動 HD ── 繁體中文語言包 (zh-TW)
================================================================

本語言包是把 wmltogether 的《ZLD:TWW HD 簡體中文語言包 v1.0.2》
以程式自動轉換成繁體中文（台灣用語）的成果。

譯名與用語
----------------------------------------------------------------
採用任天堂官方繁中譯名。依據是有官方中文的作品（曠野之息、王國之淚、
智慧的再現、織夢島、天空之劍 HD、大亂鬥特別版等）：

  塞爾達 → 薩爾達      海拉爾 → 海拉魯      加農多夫 → 加儂多夫
  王者之劍 → 大師之劍   迴旋鏢 → 飛旋鏢      精靈 → 妖精（Fairy）
  瑞託 → 利特          蒂拉 → 特托拉        梅麗 → 梅德麗
  艾瑞兒 → 阿利爾      比多 → 特里          德古大樹 → 德庫樹
  古洛克 → 克洛格      佐拉 → 卓拉          大豬怪 → 莫力布林
  惡鼠怪 → 波克布林    黑騎士 → 黑甲武士    地之神殿 → 大地神殿

「三角神力」沒有官方繁中譯名（有中文的作品都沒用這個名字），
風之律動專屬的地名人名（大海原、魔獸島、普羅羅島、庭格爾……）
也沒有，這些一律沿用民間慣用譯名。

「精靈」在原文有 Fairy 與 spirit 兩種意思，因此逐句依英文判定：
Fairy 改成「妖精」，德庫樹、加布那種 spirit 維持「精靈」。

中國用語也一併改成台灣說法（質量→品質、水平→水準、服務員→服務生、
郵遞員→郵差、抓緊時間→趕快、倒黴→倒楣、咱們→我們），清掉兒化音
（這兒→這裡、點兒→點、玩意兒→玩意……），句末的「麼」也改成「嗎」。

譯文是用 OpenCC 轉的，而 s2twp 會把一批台灣的「資訊術語」套進來，
在奇幻對白裡讀起來很怪。本包已將這類詞換回常見說法：

  型別→類型   遠端武器→遠距離武器   專案→項目   支援→支持
  物件→物品   血液迴圈→血液循環     介面→畫面（英文原文是 screen）

另外也拿掉了「進行安置」「進行投擲」這種贅詞。

上游作者說明文本是用 OCR 從 GameCube 版漢化掃出來的，因此帶有辨識錯字，
本包修正了找到的部分：

  掌提→掌握（14 處）  風之仗→風之杖   黴氣→霧氣   渲洩→宣洩
  析禱→祈禱          醅→酷           好象→好像   眼睹→眼睛
  眼哞→眼眸          磨躇→磨蹭       咋碎→砸碎   初學乍到→初來乍到
  口口相傳→口耳相傳  一朝被蛇咬十年怕井繩→……十年怕草繩


字型
----------------------------------------------------------------
遊戲內建字型只收錄簡體字圖，缺字會顯示成空白，因此本包重建了三個字型：

  CKingMsg.bffnt    對話字型      4390 → 5398 字（新增 1008 字）
  CKingMain.bffnt   選單字型       569 →  761 字（新增 192 字）
  CKingMainL.bffnt  選單字型（大）  569 →  761 字（新增 192 字）

新字圖依原字型的描邊樣式算繪後，以 BC4 壓縮並套用 Wii U GX2 tiling
寫回原有的字圖頁。既有字元的字圖索引、字寬表與未使用到的字圖頁
均保持位元組相同，不影響原本的排版。

字圖為完整反鋸齒，灰階分布與遊戲原版字圖同級，放大不會有鋸齒狀的毛邊。

CKingPic / CKingRuby / CKingZelda 三個字型經檢查不需要新增字圖。

安裝
----------------------------------------------------------------
開始前請確認：

  * 遊戲是美版（USA）WUP-P-BCZE，Title ID 0005000010143500
  * 遊戲／主機語言設為「English」
    （設成法文或西班牙文的話，遊戲會去讀 UsFrench / UsSpanish，中文不會出現）

部署方式有兩種，擇一即可：


─── 方式一　外掛式：不動到遊戲本體（推薦，限 Cemu）────────────────

中文以「圖形封包」的形式疊在遊戲上，原始遊戲檔案完全不會被修改，
想切回英文只要取消勾選就好，不必重灌。

  1. 下載 TWWHD_zhTW_CemuGraphicPack-tw-v1.0.10.zip
  2. 解壓後，把整個 TWWHD_zhTW 資料夾放進 Cemu 的 graphicPacks\
  3. 重開 Cemu，到「選項 → 圖形封包」勾選
     Traditional Chinese (zh-TW)
  4. 啟動遊戲

  ※ 要放在 graphicPacks\，別放進 downloadedGraphicPacks\ ──
    後者在更新圖形封包時會被清空。


─── 方式二　整合式：直接覆蓋遊戲檔案 ──────────────────────────

把中文檔案寫進遊戲資料本身，做出一份「本來就是中文」的遊戲資料。
實機（Loadiine）只能用這種方式。

  1. 下載 ZLD-TWW-HD-zhTW-tw-v1.0.10.zip
  2. 先備份上面「檔案」列出的那兩個原始檔案
  3. 把 content 資料夾內的檔案覆蓋到遊戲資料的相同路徑
  4. 以 Loadiine（WiiU 5.3.2 或更早韌體）或 Cemu 執行

  ※ 這個方式會改寫遊戲檔案，沒備份就回不去了，請先備份。


※ 本版僅確認美版 English 模式；不保證改名後即可適用日版。
