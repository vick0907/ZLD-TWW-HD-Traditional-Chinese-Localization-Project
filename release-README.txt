薩爾達傳說 風之律動 HD ── 繁體中文語言包 (zh-TW)
================================================================

本語言包是把 wmltogether 的《ZLD:TWW HD 簡體中文語言包 v1.0.2》
以程式自動轉換成繁體中文（台灣用語）的成果。


譯文來源
----------------------------------------------------------------
* NGC 原始版簡體中文補丁：鼯鼠工作室 / 漫遊漢化組（2007-2008）
* WiiU HD 版移植：wmltogether 及數名匿名玩家
  https://github.com/wmltogether/ZLD-TWW-HD-Chinese-Localization-Project
* 繁體化：以 OpenCC s2twp 轉換全部 5040 句訊息（4275 句有變動），
  再套用專有名詞表。MSBT 控制碼在轉換過程中完全未被觸碰。


譯名與用語
----------------------------------------------------------------
採用任天堂官方繁中譯名：

  塞爾達 → 薩爾達        海拉爾 → 海拉魯      加農多夫 → 加儂多夫
  黃金聖三角 → 三角神力    王者之劍 → 大師之劍   迴旋鏢 → 迴力鏢

中國用語也一併改成台灣說法（質量→品質、水平→水準、服務員→服務生等），
並清掉兒化音（這兒→這裡、點兒→點、玩意兒→玩意……）。
少數台灣也通行的說法（倆、咱、一會兒、鳥兒）則保留。

上游作者說明文本是用 OCR 從 GameCube 版漢化掃出來的，因此帶有辨識錯字，
本包修正了找到的部分：眼睹→眼睛、眼哞→眼眸、磨躇→磨蹭、咋碎→砸碎、
初學乍到→初來乍到。


字型
----------------------------------------------------------------
遊戲內建字型只收錄簡體字圖，缺字會顯示成空白，因此本包重建了三個字型：

  CKingMsg.bffnt    對話字型      4390 → 5372 字（新增 982 字）
  CKingMain.bffnt   選單字型       569 →  731 字（新增 162 字）
  CKingMainL.bffnt  選單字型（大）  569 →  731 字（新增 162 字）

新字圖依原字型的描邊樣式算繪後，以 BC4 壓縮並套用 Wii U GX2 tiling
寫回原有的字圖頁。既有字元的字圖索引、字寬表與未使用到的字圖頁
均保持位元組相同，不影響原本的排版。

字圖為完整反鋸齒，灰階分布與遊戲原版字圖同級，放大不會有鋸齒狀的毛邊。

CKingPic / CKingRuby / CKingZelda 三個字型經檢查不需要新增字圖。


標題畫面
----------------------------------------------------------------
Title_00.szs 裡的標題點陣圖已重繪為「薩爾達傳說 風之律動」，
採用任天堂官方繁中譯名，上方的英文「THE LEGEND OF ZELDA」一併重繪。

除了字形以外，標題的光掃遮罩（Mask）也依新字形重建，
因此進入標題畫面時的掃光會正確地沿著中文字形掃過。

安裝
----------------------------------------------------------------
開始前請確認：

  * 遊戲是美版（USA）WUP-P-BCZE，Title ID 0005000010143500
  * 遊戲／主機語言設為「English」
    （設成法文或西班牙文的話，遊戲會去讀 UsFrench / UsSpanish，中文不會出現）

部署方式有兩種，擇一即可：


─── 方式一　外掛式：不動到遊戲本體（推薦，限 Cemu）────────────────

中文以「圖形封包」的形式疊在遊戲上，原始遊戲檔案完全不會被修改，
想切回英文只要取消勾選就好，不必重灌。

  1. 下載 TWWHD_zhTW_CemuGraphicPack.zip
  2. 解壓後，把整個 TWWHD_zhTW 資料夾放進 Cemu 的 graphicPacks\
  3. 重開 Cemu，到「選項 → 圖形封包」勾選
     Traditional Chinese (zh-TW)
  4. 啟動遊戲

  ※ 要放在 graphicPacks\，別放進 downloadedGraphicPacks\ ──
    後者在更新圖形封包時會被清空。


─── 方式二　整合式：直接覆蓋遊戲檔案 ──────────────────────────

把中文檔案寫進遊戲資料本身，做出一份「本來就是中文」的遊戲資料。
實機（Loadiine）只能用這種方式。

  1. 下載 ZLD-TWW-HD-zhTW-v1.0.2-tw1.zip
  2. 先備份上面「檔案」列出的那兩個原始檔案
  3. 把 content 資料夾內的檔案覆蓋到遊戲資料的相同路徑
  4. 以 Loadiine（WiiU 5.3.2 或更早韌體）或 Cemu 執行

  ※ 這個方式會改寫遊戲檔案，沒備份就回不去了，請先備份。


※ 日版鏡像請把 permanent_2d_UsEnglish.pack 改名為
  permanent_2d_JpJapanese.pack。

----------------------------------------------------------------

  原版畫在「塞」上的劍痕也隨著換字一起移除。
* 譯文以自動轉換為主，未逐句校潤，可能仍有殘留的 OCR 錯字。
* 上游作者註明：謎題密碼沿用英文版，卡關請查英文攻略。
* 尚未經過完整實機通關測試。
